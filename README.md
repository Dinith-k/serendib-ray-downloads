## 📖 Install guides

<details>
<summary><b>💻 Windows</b></summary>

<br>

1. Run the downloaded file and follow the steps. It installs just for you. The app asks Windows for administrator permission each time you open it by hand (it needs that for the system proxy and Whole PC mode); when it starts at sign-in it does so without a prompt.
2. If Windows says it protected your PC, choose **More info**, then **Run anyway**. The installer is not code-signed yet, so Windows does not know the publisher (**Aplogon**).
3. On the last page, leave **Run on startup and connect automatically** ticked if you want it to start by itself when you sign in to Windows. You can turn it off any time in **Settings**.
4. Sign in, or create your free account.

The close button asks whether to **minimize to the tray** or **quit**, and the tray icon can connect, disconnect and quit.

**Updates:** the installed app checks for new versions by itself and installs them when you close it, or when you press **Restart and update** (**Settings > App updates**). Already have an older version? It updates to this one by itself.

</details>

<details>
<summary><b>🍎 macOS</b></summary>

<br>

1. Open the downloaded `.dmg` and drag **Serendib Ray** into **Applications**.
2. The first time, open it with **right-click > Open**, then **Open** again. The app is not notarized by Apple yet, so a plain double-click shows a warning.
3. Sign in, or create your free account.

> [!WARNING]
> **Early build.** The macOS version passes its automated tests on a Mac, but it is new. If macOS asks for your password when connecting, that is the app changing the network proxy settings.

</details>

<details>
<summary><b>🤖 Android (Serendib Ray Pro)</b></summary>

<br>

1. Open this page on your phone and download the `.apk`.
2. Open the downloaded file. Android asks you to allow installing apps from this source (your browser or Files app): allow it, go back, then tap **Install**.
3. Open **Serendib Ray Pro**, then sign in or create your free account.
4. Tap the power button. Android asks once for permission to set up the VPN connection: choose **OK**.

Serendib Ray Pro is the ad-free version of Serendib Ray. It is not on Google Play, so you install it from this file. It installs **next to** the Serendib Ray app from Google Play and does not replace it. If you have an older Pro version, this one installs over it.

## ❓ Questions

<details>
<summary><b>Is Premium really free?</b></summary>

<br>

Yes. Every server, the SNI change and the port 443 servers are free in the Windows, Mac and Android Pro apps. You only need a free account. There is no trial and no plan, and your account does not run out.

</details>

<details>
<summary><b>Why do I need an account?</b></summary>

<br>

The account keeps the free servers for real people and stops abuse: one free account per person and per device. You make it once, in the app or at [vpnlk.online/signup](https://vpnlk.online/signup), with your name, email, phone number and a password.

</details>

<details>
<summary><b>Can I use one account on more than one device?</b></summary>

<br>

Yes: **one Windows PC, one Mac and one Android phone**, all at the same time. Signing in on a new device of the same kind (a new PC, for example) moves the account there, and the old one is signed out. You can move it up to 3 times a day.

</details>

<details>
<summary><b>I already have an activation key (SRK-…)</b></summary>

<br>

It keeps working and now never expires. If the app was already activated, you stay signed in after the update. On a new device, choose **I have an activation key** under the sign-in form.

</details>

<details>
<summary><b>What does changing the SNI do?</b></summary>

<br>

The SNI is the server name your connection shows to the network. Some networks block certain names and allow others, so a different name can get through. In **Settings**, pick a tested name to see only the servers that passed a test with it, or type any name you like. With a name you typed yourself every server stays listed, but a server may not accept it, so try another server if it won't connect. The server's certificate is still checked against its own name, so the connection stays safe. A change applies the next time you connect.

</details>

<details>
<summary><b>How do I choose which apps use the VPN? (Windows)</b></summary>

<br>

In **Settings**, open **Apps through the VPN**. Choose **Only selected** (just these apps use the VPN) or **All except selected** (everything except these apps), then **Add a running app** or **Choose a program…**. The list is saved. In **System proxy** mode this only affects apps that follow the Windows proxy settings, like browsers; switch to **Whole PC** mode for games and other apps.

</details>

<details>
<summary><b>System proxy or Whole PC mode? (Windows)</b></summary>

<br>

**System proxy** (the default) is enough for browsers and most apps. **Whole PC** sends everything through the VPN, including games and apps that ignore proxy settings. Change it in **Settings > Mode** (the button at the top of the home screen takes you there).

</details>

<details>
<summary><b>Which languages does the Windows and Mac app speak?</b></summary>

<br>

English, Sinhala (සිංහල), Tamil (தமிழ்), Russian, Hindi, Chinese, Arabic, Persian, Turkish, Spanish, French and Indonesian. It follows your computer's language, and **Settings > Language** changes it at once. The translations were written with machine help, so if a text reads oddly, please tell us.

</details>

<details>
<summary><b>Is the Pro app the same as Serendib Ray on Google Play?</b></summary>

<br>

No, it is a separate app (**Serendib Ray Pro**) with the same new design. It has no ads, and Premium is free in it with your account. You can keep both installed.

</details>

<details>
<summary><b>Does it work if the account server can't be reached?</b></summary>

<br>

The app checks your account when it starts and every few hours. If it can't reach the server it keeps working for up to 3 days, then asks to check in again.

</details>
